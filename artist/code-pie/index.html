Code Pie

Code Pie is a Montreal-based indie rock band founded by singer and guitarist Enzo Palermo. Other band members are Salvatore Ciolfi (guitars), Michel Semienchuk (bass), Vince Varano (drums), Eva Boodman (trumpet) and Rebecca Lessard (cello, keys, vocals). Source: Wikipedia, CC BY-SA
